> **摘要.** 原始 DQN 已让萧炎的神经估值功法运转，却仍留下数道暗伤：`max` 放大噪声造成过高估计，单流网络没有显式拆分状态价值与动作优势，均匀回放不分卷宗信息量，$\epsilon$-贪婪探索较粗糙，标量 Q 值还会压缩完整回报分布。药老的改良思路不是凭空换一门功法，而是逐处修补：Double DQN 分开选择与评估，Dueling DQN 改造网络表示，优先经验回放（PER）重排纳戒卷宗，Rainbow 再把多项扩展合为一体。

> 本章中的药老改卷、纳戒卷宗与功法组合均为教程原创比喻，不是原著桥段或人物台词。药老代表价值评估与模型思维的导师，萧炎才是采取动作的智能体。

上一章的基础配方有三件核心组件：神经 Q 函数 $Q_\theta$、回放缓冲 $\mathcal{D}$ 和目标网络 $Q_{\theta^-}$。它用以下目标校准估值：

**原始 DQN 单步目标式。** 它回答“用目标网络对下一状态取最大值时，这条经验的回归标签是多少？”

$$
y = r + \gamma \max_{a'} Q_{\theta^-}(s',a')
$$

现在药老把这张配方摊开逐项追问：还会在哪里走火入魔？后续扩展分别修改目标、网络头、回放采样器、多步回报、探索机制或预测对象。它们并不都解决同一问题，也不保证简单相加就更强。

教程进度可把这一章叫作“斗灵阶段的改良课”：不是换一个更响亮的境界名，而是诊断每处误差从何而来。Double、Dueling 与 PER 解决的是不同问题；复杂组件更多，不自动代表算法更强，环境、算力与消融证据才决定该不该用。

## 第一处暗伤：`max` 带来的过高估计

原始 DQN 会对带噪声的动作价值取 `max`。若多个招式的估值都不确定，最高者往往既包含真实优势，也混入了恰好为正的估计误差，于是最大值出现系统性乐观倾向。

机制很具体：同一组带噪数字先负责选出"看起来最强"的招式，再负责给这招打分。被选者更可能只是噪声碰巧偏高，而非真实回报更大。热血不能替代校准；被网络喊得最响的 Q 值，未必就是最可靠的 Q 值。

在期望上，这产生了向上的偏差：

**最大化估计的乐观偏差不等式。** 它回答“为什么先对带噪估计取最大值，平均后通常不低于先求平均再取最大值？”这是一条由最大值的凸性带来的不等式，不是说每一个样本都必然过估计。

$$
\mathbb{E}\left[\max_a \hat Q(s,a)\right] \geq \max_a \mathbb{E}[\hat Q(s,a)]
$$

这不只是数值看起来虚高。DQN 会自举，偏高目标会沿更新传播到更早状态；若行为再对这些估值贪婪，萧炎就可能反复追逐被噪声粉饰的招式。

最小例子：两招真实价值都为 $0$，一次估计恰为 $[-1,+1]$，取最大得到 $+1$；另一次可能是 $[+1,-1]$，最大仍是 $+1$。各动作误差单独都可均值为零，选择后的最大值却向上。反例是所有估计完全无噪且准确，此时左右两边相等，不会凭空产生过估计。

## Double DQN：一人选招，一人评分

**Double DQN** 的药方是解耦动作选择与动作评估。在线网络先选下一招：

**Double DQN 在线选招式。** 它回答“按当前在线网络，下一状态中哪一招估值最高？”若有并列项，实现需明确平局规则。

$$
a^* = \arg\max_{a'} Q_\theta(s',a')
$$

目标网络再给这招评分：

**Double DQN 目标网络评分式。** 它回答“在线网络选中的动作，由滞后目标网络评成多少训练目标？”

$$
y = r + \gamma Q_{\theta^-}(s', a^*)
$$

写成一行：

**Double DQN 合并目标式。** 它把“在线选招、目标评分”合并为一个可直接实现的表达式。

$$
y = r + \gamma Q_{\theta^-}\left(s', \arg\max_{a'} Q_\theta(s',a')\right)
$$

目标网络不是完全独立的第二位裁判，只是在线网络的滞后副本；二者误差仍可能相关，Double DQN 因此是**减轻**而非保证消灭过高估计。不过这点时间差已能缓和"同一噪声既选招又评分"的问题。

例如在线网络把两招估成 $[8,7]$，所以选第一招；目标网络却估成 $[5,9]$。原始 DQN 用目标网络自身的最大值 $9$，Double DQN 用目标网络对**在线所选第一招**的评分 $5$。这不是总会更小的定理，却展示了解耦如何拒绝目标网络自己“选中它恰好高估的招”。

因此 Double DQN 是最小改造，不是全新架构。原始 DQN 本就有在线网络 $Q_\theta$ 与目标网络 $Q_{\theta^-}$；现在只重新分工：前者凭当前判断选贪婪动作，后者用滞后参数评估该动作。

```python
def double_dqn_targets(
    rewards: torch.Tensor,
    terminals: torch.Tensor,
    next_q_online: torch.Tensor,
    next_q_target: torch.Tensor,
    gamma: float,
) -> torch.Tensor:
    """Double DQN 目标：在线网络选择贪婪动作，目标网络评估。"""
    with torch.no_grad():
        next_actions = next_q_online.argmax(dim=1, keepdim=True)
        next_values = next_q_target.gather(dim=1, index=next_actions).squeeze(1)
        targets = rewards + gamma * (1.0 - terminals) * next_values
    return targets
```

## Dueling DQN：状态底蕴与招式优势分炉修炼

原始单流 DQN 直接为每个动作输出 Q 值，内部同时要表达两件事：当前状态本身的底蕴，以及每个动作相对其他动作好多少。概念上可写成状态价值

**策略下的状态价值—动作价值关系式。** 它回答“在策略 $\pi$ 下，状态价值怎样由各动作价值按动作概率平均？”

$$
V(s) = \mathbb{E}_{a \sim \pi}[Q(s,a)]
$$

来描述第一部分，再用优势

**动作优势定义式。** 它回答“动作 $a$ 的价值比该状态在当前策略下的平均价值高或低多少？”

$$
A(s,a) = Q(s,a) - V(s)
$$

描述第二部分，并按定义得到 $Q(s,a)=V(s)+A(s,a)$。这里的 $V$ 与 $A$ 若谈真实函数，应对应同一策略；dueling 网络中的两个输出流则是学习到的表示，需靠聚合约束解决不可辨识性。

这种拆分在许多动作价值相近的状态尤其有用。单次 TD 样本只监督实际采取动作的 Q 输出；若把"此状态总体不错"放进共享的 $V(s)$ 流，经过该状态的不同动作样本都能帮助更新这部分信息。贪婪决策真正关心同一状态下各动作的相对差距，优势流 $A(s,a)$ 正好专门表达这种差距。

**Dueling DQN** 把这个直觉落成架构：共享躯干之后分成两个头，一个输出标量 $V_\theta(s)$，另一个输出每个动作的 $A_\theta(s,a)$，最后用带可辨识性修正的公式重新合成 Q 值：

**均值中心化的 Dueling 聚合式。** 它回答“怎样合并状态底蕴与各招优势，同时消除 $V$、$A$ 分解的不唯一性？”

$$
Q(s,a) = V(s) + \left(A(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A(s,a')\right)
$$

减去平均优势不可省略。若只写 $Q=V+A$，给 $V$ 加任意常数并从所有 $A$ 中减掉同一常数，Q 完全不变，两个分支便无法唯一分工。把优势中心化到均值为零，为分解选定一致表示并改善优化。

数字例子：若价值头输出 $V=5$，优势头输出 $[2,0,-2]$，均值为 $0$，合成 Q 仍是 $[7,5,3]$。若优势头输出 $[4,2,0]$，均值为 $2$，中心化后仍是 $[2,0,-2]$，Q 仍为 $[7,5,3]$；这说明整体平移优势头不应改变动作价值。

Dueling DQN 不改贝尔曼目标，只改表示：一条分支回答"此境整体如何"，另一条回答"哪一招相对更强"。

所以 dueling 属于架构改进，不是探索技巧，也不是目标修正。它不改变更新规则，能够和 Double DQN、不同回放采样器组合。

```python
class DuelingQNetwork(nn.Module):
    """带 V(s) 和 A(s, a) 头部的共享躯干；重组为 Q = V + (A - mean A)。"""

    def __init__(self, state_dim: int, hidden_dim: int, n_actions: int) -> None:
        super().__init__()
        self.torso = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
        )
        self.value_head = nn.Linear(hidden_dim, 1)
        self.advantage_head = nn.Linear(hidden_dim, n_actions)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """前向传播：状态 -> dueling Q 值。"""
        h = self.torso(x)
        v = self.value_head(h)
        a = self.advantage_head(h)
        a_centered = a - a.mean(dim=1, keepdim=True)
        return v + a_centered
```

## 优先经验回放：纳戒先抽最值得重练的卷宗

均匀回放对纳戒里的每份经历一视同仁，简单却未必高效：网络早已预测准确的普通转移仍会反复出现，而罕见、出乎意料的关键遭遇可能久候不到。

**优先经验回放**（Prioritized Experience Replay, PER）让高优先级卷宗更常被抽到。转移 $i$ 的采样概率为：

**PER 随机优先采样概率式。** 它回答“根据每条经验的优先级，怎样归一化得到抽样概率？”

$$
P(i) = \frac{p_i^\alpha}{\sum_k p_k^\alpha}
$$

通常令 $p_i=|\delta_i|+\epsilon$，其中 $\delta_i=y_i-Q_\theta(s_i,a_i)$ 是该转移最近一次计算得到的 TD 误差。取绝对值后，高估与低估都被视为值得纠正；小常数 $\epsilon>0$ 保证每份卷宗仍有非零机会再被看到。指数 $\alpha$ 控制偏爱程度：$\alpha=0$ 退化为均匀采样，$\alpha$ 越大，越集中重放高误差样本。

但大 $|\delta|$ 只是"有用"的代理，不是天选真理。随机环境会让同一状态—动作产生不同奖励，旧网络留下的优先级会过时，目标网络也可能给出带噪自举目标。若只贪婪抽取最大误差，萧炎可能被不可约噪声困在同几卷里。采用 $\alpha<1$ 的随机优先采样，可在偏向高误差卷宗的同时保留全缓冲覆盖。

例如两条经验优先级为 $1$ 与 $9$。当 $\alpha=1$ 时，采样概率为 $0.1$ 与 $0.9$；当 $\alpha=0$ 时，两者都变成 $0.5$。若第二条只是随机奖励导致永远有大误差，盯着它练九成轮次未必有益，这正是 PER 仍需随机性和校正的原因。

优先采样改变了原本均匀回放的训练分布，高误差卷宗会对损失产生过多影响。重要性采样用抽取概率的倒数为每个样本加权，以校正相对于均匀回放目标的分布偏移：

**PER 重要性采样权重式。** 它回答“高概率样本被多抽后，怎样缩小其单次损失贡献以补偿分布偏移？”

$$
w_i = \left(\frac{1}{N \cdot P(i)}\right)^\beta
$$

$\beta=1$ 时，相对于均匀缓冲经验损失可得到完整的重要性校正：若某转移被多采样 $k$ 倍，单次贡献相应缩小。$\beta=0$ 则不校正。PER 常把 $\beta$ 从较小值逐渐退火到 1：早期容许一定偏差以集中学习，后期逐步恢复校正。实践还会用 minibatch 中或缓冲中的最大 $w_i$ 归一化权重，控制梯度尺度。这里的"校正"针对采样分布，不等于为非线性 TD 学习提供普遍收敛保证。

## 三味辅药：多步目标、噪声网络与分布强化学习

药老的改良卷上还有三味组件，它们分别改变奖励传播、探索方式与预测对象。

**多步回报**（multi-step returns）让萧炎先亲历若干步奖励，再从第 $n$ 步后的价值自举：

其中 $R_t^{(n)}=R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{n-1}R_{t+n}$ 是前 $n$ 步真实奖励的折扣和。

**DQN 的 $n$ 步自举目标式。** 它回答“使用前 $n$ 步真实奖励后，怎样从第 $n$ 个后继状态的最大 Q 值接上未来？”

$$
R_t^{(n)} + \gamma^n \max_{a'} Q(S_{t+n},a')
$$

它能比单步目标更快地把奖励向前传播，代价是更高方差；若回放轨迹来自旧行为策略，还会引入额外的异策略偏差。

若三步奖励为 $1,0,4$，$\gamma=0.5$，第 3 步后最大 Q 为 $8$，则三步目标是 $1+0.5\times0+0.5^2\times4+0.5^3\times8=3$。若片段在第三步前真正终止，自举项应消失；若只是数据切片到此结束，不能自动把它当终止。

这与 MC/TD 一章直接相连：单步 DQN 对应 TD(0) 式目标，多步 DQN 则在自举前先使用一段真实奖励。Rainbow 借此让稀疏奖励更快沿回放轨迹向前面的状态—动作传播。

**噪声网络**（Noisy Nets）把手工设置的 $\epsilon$-贪婪，换成网络内部可学习的参数噪声。它不是每一步独立乱出一招，而是采样一套带噪价值函数并相对它贪婪行动，因此可形成时间上更一致的探索方向。

**分布强化学习**（distributional RL）不再把未来压成单个均值，而是学习回报分布 $Z(s,a)$，其期望才是 $Q(s,a)=\mathbb{E}[Z(s,a)]$。策略通常仍按期望回报选动作，但训练对象保留了多峰与罕见结果等更丰富结构。这里的 distributional 指 return distribution，并非多机器分布式计算；C51 的类别投影细节超出本章范围。

两个动作都可能有 $Q=5$：甲确定得到 $5$，乙以一半概率得 $0$、一半概率得 $10$。标量 Q 看不出差异，回报分布却能保留风险形态；标准 Rainbow 仍主要按期望选招，因此“学到分布”也不等于自动采用风险厌恶策略。

## Rainbow：六种改良合成一炉

**Rainbow** 像把六种改良同炉炼制，但仍是严谨算法组合而非玄学叠加：

1. Double DQN；
2. 优先经验回放；
3. Dueling 网络；
4. 多步回报；
5. 带 C51 的分布强化学习；
6. 噪声网络。

Rainbow 的贡献不在于声称六件组件全都新创，而在**整合与消融**（ablation）：把主要 DQN 扩展放进同一个 Atari 智能体，再逐件拿掉，检验组合后谁仍真正贡献性能。

这很重要，因为改进不会必然线性叠加。两味组件可能治疗同一处暗伤，一味也可能削弱另一味的边际作用。阅读 Rainbow，既要看整套智能体，也要看消融证据。

> **改良卷段子。** 三十版网络在河东，一次消融到河西；莫欺基础 DQN 配方朴素，也莫把六味辅药一股脑当作斗圣丹。药老真正要看的，是拿掉哪一味后证据会变差。这是教程原创段子，不是原著对白。

原论文报告，在 no-op starts 评估下，Rainbow 达到约 223% 的中位人类归一化 Atari 分数；每个评估片段先执行 0 到 30 次随机数量的"无操作"，以扰动确定性开局。消融结果比单个汇总数更值得看：优先回放、多步回报与分布强化学习贡献最大，噪声网络帮助较温和；Double DQN 与 Dueling DQN 在完整 Rainbow 组合中的汇总增益不显著。论文提出的可能解释包括有限分布支撑减轻过高估计，以及分布头部分吸收 dueling 的表示收益。这是对实验结果的解释，不应外推成这些组件在所有环境都无用。
