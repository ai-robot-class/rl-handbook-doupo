> **摘要.** 在上一章的教学棋盘里，药老知道每一步的完整转移规则，因而能用动态规划评估一套修炼方案。真正踏入斗气大陆后，这张规则图并不存在：萧炎只能亲自行动并记下经历。蒙特卡洛（MC）等一整段历练结束再复盘完整回报；时序差分（TD）每走一步，就用眼前奖励和对下一状态的估计修正当前判断。本章仍只做**预测**：策略固定，学习的是它会带来怎样的状态价值。

> 本章的斗破情境均为教程原创类比，并非原著情节或人物原话。萧炎对应智能体，斗气大陆对应环境；药老在这里负责讲解价值评估，而不是替萧炎输出策略。即时奖励 $R_{t+1}$ 与长期价值 $V(s)$ 也始终是两回事。

动态规划精确而干净，却假设能访问 $p(s', r \mid s,a)$。好比药老若掌握每条山路、每只魔兽与每种结果的概率，便能在书案前算完全部可能。但在多数 RL 问题中，环境模型不可用。萧炎可以行动并观察 $S_t$、$A_t$、$R_{t+1}$ 和 $S_{t+1}$，却不能枚举每个可能的下一状态，也不能直接对未知转移分布取平均。

因此本章只问一个窄而关键的问题：若修炼策略 $\pi$ 已经固定，怎样从采样到的整段历练或单步转移中估计状态价值函数 $v_\pi(s)$？Sarsa 和 Q-learning 那样的控制方法留到下一章；此处做的是 **无模型预测**（model-free prediction）。

这一步像从“斗师”走向“大斗师”：学会在没有环境卷轴时从样本估值。等级只描述教程认知负担，不代表 TD 必然胜过 MC。短片段、终局回报清晰时 MC 可能更合适；持续任务或片段极长时，TD 能及时更新的优势才更突出。

## 离开教学棋盘：告别动态规划

对于一个固定策略，动态规划使用贝尔曼期望更新：

**基于完整模型的迭代策略评估式。** 它回答“若能枚举全部动作与环境结果，怎样更新固定策略的状态价值？”

$$
v_{k+1}(s) = \sum_a \pi(a \mid s) \sum_{s',r} p(s',r \mid s,a) \left[r + \gamma v_k(s')\right]
$$

内层求和 $\sum_{s',r} p(s',r \mid s,a)[r + \gamma v_k(s')]$ 正是动态规划最依赖"全知规则"之处。要计算它，萧炎必须知道完整的一步模型：从 $(s,a)$ 能到达哪些下一状态、可能出现哪些奖励，以及每一对 $(s', r)$ 的概率。现实历练不会把这份卷轴交到手中；智能体无法站在环境之外检视转移分布，只能亲自交互。

无模型预测保留贝尔曼思想，却改换了获取期望的办法：不再枚举所有可能，而是把斗气大陆本身当作采样器。萧炎采取一次动作，收下一次即时奖励并抵达一个下一状态；这条真实转移，就是关于"若有模型，动态规划本会算出的期望"的一份证据。单次遭遇可能走运或倒霉，样本因而有噪声；大量经历仍会把价值估计逐渐拉向同一个对象——固定策略下的期望回报。

药老给出两本复盘册：MC 册写完一整段历练才结算，TD 册每走一步便修正一次。两者都从经验估计价值，差别在于拿经验的哪一部分作为学习目标。

## 蒙特卡洛预测：历练结束再复盘

**蒙特卡洛预测**（Monte Carlo prediction）像一次完整历练后的总复盘：萧炎每次访问状态 $s$ 后，都等到该段经历终止，再把此后实际得到的回报记入账册并取平均，以此估计 $v_\pi(s)$。这里的期望就是价值函数，

**固定策略状态价值定义式。** 它回答“在状态 $s$ 之后始终遵循 $\pi$，完整回报的期望是多少？”

$$
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s],
$$

而样本是在环境中遵循策略 $\pi$ 生成的完整回报。假设一个片段在时刻 $t$ 访问了状态 $s$。那次访问的回报是此后观测到的折扣奖励总和：

**单条轨迹的折扣回报式。** 它回答“这一次访问之后实际发生的奖励序列，折算到时刻 $t$ 共是多少？”

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots
$$

这个 $G_t$ 是随机变量"回报"的一次样本，而它的期望定义了 $v_\pi(s)$。一趟历练只有一本带运气成分的实录；反复经历才积成许多样本。MC 把每次访问该状态后的真实回报汇总，并用样本均值作为价值估计：

**蒙特卡洛样本均值估计式。** 它回答“收集到 $N(s)$ 次完整回报后，怎样用平均数估计状态价值？”

$$
V(s) = \frac{1}{N(s)} \sum_{i=1}^{N(s)} G^{(i)}(s)
$$

要点是，更新完全不使用转移概率 $p(s',r \mid s,a)$。药老不让萧炎猜"从 $s$ 还可能发生什么"，只复盘访问 $s$ 后确实发生过什么，再将多次结果平均。因此 MC 是无模型方法，却不是逐步在线更新：普通 MC 必须等片段终止，届时 $G_t$ 才完整可知。

数字例子：三次访问同一状态后的完整回报为 $8,-1,5$，则 MC 估计为 $(8-1+5)/3=4$。若只挑最好的一次写成 $8$，那不是期望估计，而是幸存者偏差。另一个反例是把即时奖励当回报：某状态离终点还三步，奖励序列为 $0,0,10$；取 $\gamma=0.9$ 时，第一次访问的回报为 $8.1$，不是眼前的 $0$。

两种记账规矩都很常见：

- **首次访问 MC（first-visit MC）：** 在每个片段中，只从该状态第一次出现时更新它。
- **每次访问 MC（every-visit MC）：** 从该状态在片段中的每次出现都更新。

若一趟山谷试炼绕路后多次回到同一地点，首次访问 MC 只记第一次抵达后的回报，因此每个片段对每个状态最多贡献一个样本；每次访问 MC 则把每次出现都纳入。两者都使用完整回报，分歧只在于哪些访问有资格入账。

一个首次访问蒙特卡洛预测过程如下：

```
输入：待评估的策略 pi
对所有状态 s 任意初始化 V(s)
对所有状态 s 把 Returns(s) 初始化为空列表

永远重复，或重复选定数量的片段：
    生成一个遵循 pi 的片段：
        S_0, A_0, R_1, S_1, A_1, R_2, ..., S_{T-1}, A_{T-1}, R_T

    G <- 0
    对 t = T-1, T-2, ..., 0：
        G <- gamma * G + R_{t+1}
        如果 S_t 未出现在 S_0, S_1, ..., S_{t-1} 中：
            把 G 追加到 Returns(S_t)
            V(S_t) <- average(Returns(S_t))
```

因为 MC 使用真实采样的完整回报，而不拿尚未学准的未来价值来垫脚，首次访问 MC 在通常的片段式设定下给出无偏的样本估计。代价是高方差：从访问到终止之间的每次随机遭遇都会进入回报，一次罕见奇遇或惨败就可能把估计推离典型水平。药老若坚持"走完全程再评卷"，就免去自举偏差，却必须承受整段命运起伏。

这里的“完整”必须尊重终止语义。真正达到任务终点（`terminated`）时，终止状态的后续价值为零；若只是到达外部时间上限（`truncated`），底层任务可能仍会继续。把截断一律当作死亡终点会系统性低估长任务的价值，是否自举应依据环境 API 与任务定义处理。

## 时序差分预测：每走一步便校准

**时序差分预测**（Temporal-difference prediction）同样不需要环境模型，却改变了复盘时机。MC 必须等完整回报 $G_t$ 揭晓；最简单的 TD 方法 TD(0) 则像药老边走边点拨——一看到下一个奖励和下一状态，就立刻更新。

它能立刻学习，是因为 TD(0) 使用一步目标。经历转移 $S_t, A_t, R_{t+1}, S_{t+1}$ 后，先把已经到手的即时奖励与对下一状态长期价值的当前估计相加，作为 $V(S_t)$ 的新参照。注意：奖励是这一步收到的信号，价值是此后长期回报的期望，二者不可混写：

**一步 TD 目标式。** 它回答“看到一步真实奖励与下一状态后，当前状态应向哪个临时目标靠近？”

$$
\text{TD target} = R_{t+1} + \gamma V(S_{t+1})
$$

然后它让旧的估计朝该目标移动一小步：

**TD(0) 状态价值更新式。** 它回答“以步长 $\alpha$，把当前估值向一步 TD 目标移动多少？”

$$
V(S_t) \leftarrow V(S_t) + \alpha \left[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\right]
$$

方括号内的量是 **TD 误差**（TD error）：

**一步 TD 误差定义式。** 它回答“新的一步目标与更新前估值相差多少？”

$$
\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)
$$

它衡量新旧两个预测之间的差异。转移之前，萧炎对 $S_t$ 的判断是 $V(S_t)$；收到奖励并落到 $S_{t+1}$ 后，药老让他用"真实奖励 + 下一状态的折扣价值"形成修订后的一步预测。新预测更大就上调 $V(S_t)$，更小就下调。

数字例子：若 $V(S_t)=4$，收到 $R_{t+1}=1$，下一状态估值 $V(S_{t+1})=8$，$\gamma=0.5$，则目标为 $5$、TD 误差为 $1$。取 $\alpha=0.2$ 后，新估值为 $4.2$，而不是直接跳到 $5$。若下一状态是真正终止态，后继价值为零，目标只剩即时奖励；若只是时间截断，则不能未经判断就清零。

TD 正好把两种旧思想熔在一炉。像 MC 一样，它从真实采样经验学习，不需要动态 $p(s', r \mid s,a)$；像动态规划一样，它会 **自举**（bootstraps），因为目标含有另一个尚在学习的估计 $V(S_{t+1})$，而不是一直等到终局。可以把它理解成：用"一个真实奖励"把前后两个价值判断接起来，让当前猜测向下一步猜测靠拢。

对于策略评估，表格 TD(0) 过程是：

```
输入：待评估的策略 pi
参数：步长 alpha，取值 (0, 1]
对所有非终止状态 s 任意初始化 V(s)
令 V(终止态) = 0

永远重复，或重复选定数量的片段：
    初始化 S

    重复直到 S 为终止态：
        根据 pi(. | S) 选择 A
        采取动作 A，观察 R 和 S'
        V(S) <- V(S) + alpha [R + gamma V(S') - V(S)]
        S <- S'
```

关键差别藏在更新位置：TD(0) 不等试炼结束后沿轨迹倒查，而是在历练途中每次转移后立刻更新。因此遇到极长片段，甚至没有自然终点的持续任务时，TD 仍可一路学习。

学习率 $\alpha$ 决定一条新经历能改动旧判断多少。小 $\alpha$ 像稳扎稳打、缓慢吸收多次点拨；大 $\alpha$ 会迅速响应新经验，但更容易被一次偶然遭遇带偏。

## 两种复盘代价：偏差与方差

药老不会把 MC 与 TD 简化成"谁更强"；它们交换的是偏差与方差。

MC 使用完整回报 $G_t$。只要片段确实按策略 $\pi$ 采样，这就是 $v_\pi(s)$ 所定义随机回报的直接样本，因此偏差低；但漫长历练里的每场随机遭遇都会影响终局，方差便高。

TD(0) 使用一步目标 $R_{t+1} + \gamma V(S_{t+1})$。自举前只采样一个奖励，方差通常较低；可是只要 $V(S_{t+1})$ 尚未学准，目标就带偏差，而修炼初期它往往确实不准。

所以 MC 等得久，换来不依赖当前价值猜测的目标；TD 学得早，代价是拿尚不可靠的未来估计自举。选择哪一种，要看片段长度、奖励噪声和当前价值函数的误差，而不是看哪本功法名字更响。

TD 能在线更新的能力是一个重要的实际优势。它可以在片段进行中学习，并且可以自然地应用于那些无法等待终止的持续任务。

## $n$ 步桥梁：走多远再听药老判断

MC 与 TD(0) 是同一家族的两个端点。若萧炎先亲自走 $n$ 步、收集 $n$ 个真实奖励，再让药老用下一状态价值补完未来，便得到 **$n$ 步回报**（n-step return）：

**$n$ 步自举回报式。** 它回答“先使用多少步真实奖励，再从第 $n$ 个后继状态的估值接上未来？”

$$
G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^n V(S_{t+n})
$$

$n=1$ 时就是 TD(0)；$n$ 一直延伸到片段末尾时，就变成 MC 回报。更大的 $n$ 通常减少自举带来的偏差，却增加采样回报的方差。TD($\lambda$) 与资格迹（eligibility traces，此处只作预告）进一步以指数衰减权重组合多个 $n$ 步目标。

例如未来奖励依次为 $2,4$，$V(S_{t+2})=10$，$\gamma=0.5$，则二步回报为 $2+0.5\times4+0.5^2\times10=6.5$；一步 TD 若 $V(S_{t+1})=7$，目标为 $5.5$。两者不同并不意味着谁算错，而是采用了不同长度的真实证据与不同位置的自举估计。

## 原创训练局：用二十一点演示两种复盘

为把抽象的回报做成可运行实验，本教程虚构药老摆下一局纸牌训练，并使用标准 **二十一点**（Blackjack）环境；这不是《斗破苍穹》原著情节。萧炎扮演玩家，目标是让手牌点数比庄家更接近 21 且不爆掉。人头牌算 10；若一张 A 可算 11 而不爆掉，它就是 **可用的**（usable）。

这局训练很适合无模型预测：药老不交出发牌转移表，萧炎只得到每局实际出现的状态、动作和奖励序列。脚本中的状态是标准表格二十一点观测：

**二十一点表格状态表示式。** 它回答“本示例用哪三个可见量索引价值表？”在这套已知规则下，它被当作足以决策的状态表示；在一般部分可观测任务中，观测未必等于完整环境状态。

$$
S_t = (\text{玩家点数}, \text{庄家明牌}, \text{可用 A 标志})
$$

动作集合很小：`0` 是 **停牌**（stick），`1` 是 **要牌**（hit）。为了只练"看懂一套策略"而不练"改良策略"，规则固定为点数达 20 或 21 时停牌，否则要牌。萧炎此时无权换招，只估计该策略的价值函数，

**二十一点固定策略价值式。** 它回答“在指定牌面按固定规则继续行动，终局回报的期望是多少？”

$$
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s],
$$

样本来自许多实际对局。胜、负、平的终局奖励分别是 $+1$、$-1$、$0$。奖励只在一局结束时出现，于是 MC 的含义格外直观：访问某状态后的完整回报，就是这局最后的结果。

完整脚本直接实现牌局动态，不依赖外部环境库。发牌、检查可用 A、执行固定策略和生成片段都写成普通 Python 函数，相当于把这座小型训练场的规则摊开给读者核对。

```python
def fixed_policy(state: State, stick_threshold: int = 20) -> int:
    """高点数时停牌，否则要牌。0 = 停牌，1 = 要牌。"""
    player_sum, _, _ = state
    return 0 if player_sum >= stick_threshold else 1
```

片段生成器返回 `(state, action, reward, next_state)` 形式的转移。多数要牌动作只推进局面，奖励为 `0.0`；爆牌时该步奖励为 `-1.0`，下一状态是终止态；停牌后由庄家完成流程，最后一条转移收到 `-1.0`、`0.0` 或 `1.0`。这再次提醒我们：中间状态可以很有长期价值，即时奖励却仍为零。

```python
if action == 1:
    player.append(draw_card(rng))
    if is_bust(player):
        episode.append((state, action, -1.0, None))
        return episode
    next_state = observation(player, dealer)
    episode.append((state, action, 0.0, next_state))
    continue
```

首次访问 MC 像药老在牌局收官后先从终点向前算出每个时刻的回报，再按正序翻阅记录；同一状态一局只采用最早那次访问对应的样本。下面用增量式样本均值更新，无需真的保存所有历史回报列表。

```python
returns = 0.0
returns_by_time = [0.0] * len(episode)
for t in range(len(episode) - 1, -1, -1):
    _, _, reward, _ = episode[t]
    returns = reward + gamma * returns
    returns_by_time[t] = returns

visited = set()
for (state, _, _, _), returns in zip(episode, returns_by_time):
    if state in values and state not in visited:
        counts[state] += 1
        values[state] += (returns - values[state]) / counts[state]
        visited.add(state)
```

TD(0) 可以在每条转移到来后立即动笔。为了让 MC 与 TD 共用同一个牌局生成器，本示例先完成整局，再按发生顺序逐条重放转移并执行一步 TD 更新；这不改变 TD(0) 的目标，但这里演示的更新调度不是严格在线。`next_state` 为终止态时，下一状态价值定义为零；否则就从当前的下一牌面价值估计自举。

```python
for state, _, reward, next_state in episode:
    next_value = 0.0 if next_state is None else values.get(next_state, 0.0)
    target = reward + gamma * next_value
    values[state] += alpha * (target - values[state])
```

运行 `200_000` 个片段后，脚本会打印示例价值，并打开四面板价值曲面：MC 与 TD(0) 各按有/无可用 A 分开。具体数字随随机种子变化，但正负方向应能解释。例如 `(20, 10, False)` 在"20 点停牌"策略下通常不错：萧炎已有强牌，即使庄家明牌为 10；`(13, 2, False)` 往往很差：固定策略迫使他继续要牌，补牌后仍可能牌弱或直接爆掉。

别把价值曲面误读成最优功法：这里没有控制，萧炎不会依据学到的价值改变行为。药老要展示的只是预测机制——MC 等整局结果再平均完整回报，TD(0) 一拿到奖励与下一状态便推动当前价值。

> **复盘册小剧场。** MC 说“三十步走完再谈成败”，TD 说“三十年太久，每一步都可校准”。药老摇头：“莫欺任一册页薄；一个少自举偏差，一个能及时学习。”这是教程原创段子，不是原著台词，也不意味着两者存在固定强弱顺序。
