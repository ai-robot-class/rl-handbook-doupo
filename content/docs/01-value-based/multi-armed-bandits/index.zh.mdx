> **摘要.** 药老为萧炎摆出 $k$ 座外观相同、聚气效率未知的聚气台。每次修炼只能选择一座，并立刻得到一次斗气增益；这一次增益是**奖励**，而对该聚气台长期收益的估计才是**动作价值**。没有境界状态、没有场景转移，也没有延迟后果——只留下强化学习最纯粹的一道难题：是利用眼下最好的选择，还是探索尚未看清的可能？

<Callout title="原创教学情境" type="info">
本章的“聚气台试炼”是为讲解算法设计的教程原创情境，并非《斗破苍穹》原著情节。人物只承担稳定的概念映射：萧炎是智能体，斗气大陆是环境，药老是帮助估计价值与校准策略的导师。
</Callout>

引言中的强化学习是一段连续修炼：萧炎观察状态、采取行动、获得奖励，再进入新状态。进入马尔可夫决策过程之前，药老先把世界压缩成一间只放着聚气台的修炼室。这里每轮都回到同一种局面，选择不会改变下一轮的处境，却仍然不能一眼看穿哪座聚气台最好。

这个最小问题就是 **$k$ 臂赌博机**。经典名称来自有 $k$ 个拉杆的老虎机；在本章的对应关系中，每个“臂”是一座聚气台，每次选择都会从该台未知的奖励分布中产生一次斗气增益。萧炎希望在有限的修炼轮次里积累尽可能多的奖励。每一步只有三件事：选择一座台、观察一次奖励、更新对这座台的认识。

于是，**探索–利用权衡** 像异火一般被单独提炼出来。利用（exploitation）是登上当前估计回报最高的聚气台；探索（exploration）是试一座证据不足的台，因为它可能藏着更高的长期收益。在完整 RL 中，这个选择还会与状态访问和时序信用分配交织；在赌博机中，萧炎只需直面“不确定性是否值得一次尝试”。

按全书统一路线，本章来到“斗者阶段”：从认清状态、动作与奖励，进一步练习探索—利用这股基本功。这不代表赌博机比后面的算法低劣；广告选择、临床试验分配等真实问题本来就可能是赌博机，此时硬上复杂深度网络，未必比一个可解释的 UCB 更好。境界名只标记教程进度，不给算法排战力榜。

## $k$ 座聚气台：赌博机设定

共有 $k$ 个动作，我们仍按标准术语称之为臂。在每个时间步 $t$，萧炎选择一个动作 $A_t \in \{1, \ldots, k\}$，并收到一个从该臂奖励分布中采样得到的标量奖励 $R_t$。

在 **平稳**（stationary）赌博机中，每座聚气台的奖励分布始终不变：今天选择动作 $a$ 与明天再选同一动作，样本都来自同一分布。因此，每个臂有固定的期望奖励，也就是长期平均收益。动作 $a$ 的 **动作价值**（action-value）定义如下。

**真实动作价值定义式。** 它回答“若反复选择同一座聚气台，单次奖励的长期平均是多少？”

$$
q_*(a) = \mathbb{E}[R \mid A = a].
$$

药老会提醒萧炎分清两层含义。第一，$q_*(a)$ 是环境中该奖励分布的真实均值，并不因萧炎的信心而改变。第二，萧炎从来不能直接看到 $q_*(a)$，只能看到一次次带噪声的 $R_t$。因此，**奖励不等于价值**：奖励 $R_t$ 是一次修炼实际获得的即时样本，价值 $q_*(a)$ 是重复选择该动作时的期望。萧炎只能用样本维护估计 $Q_t(a)$，让它逐渐逼近 $q_*(a)$。星号表示真实或最优版本；$Q_t(a)$ 则只是时刻 $t$ 掌握的估计，可能因一次好运而偏高，也可能因一次失手而偏低。

例如甲台（动作 $a_1$）奖励为 $0$ 或 $10$，各有一半概率，因此 $q_*(a_1)=5$；第一次恰好得到 $10$，只说明 $R_1=10$，不能把真实价值也写成 $10$。乙台（动作 $a_2$）每次固定给 $6$，故 $q_*(a_2)=6$。若只看第一次，甲似乎更强；若看期望，乙才是最优臂。这正是“今日河东的一次好运，不代表三十轮后仍在河东”。

下一章会解除修炼室的封印，加入会随行动改变的状态和转移。那时，动作价值不仅由即时奖励决定，还要把通往未来状态的后果算进去。赌博机可以看作只有一个状态、过去不约束未来的特例。

## 修炼代价：累积后悔值

只看平均奖励可以判断收获多少，但药老还想知道：若早知最优聚气台，萧炎因为试错少积累了多少斗气？这正是 **后悔值**（regret）衡量的量。

令 $a^* = \arg\max_a q_*(a)$ 为一个最优臂。若萧炎在时刻 $t$ 选择 $A_t$，期望的单步后悔值就是最优臂真实价值与所选臂真实价值之差：

**单步伪后悔值。** 它回答“这一轮所选动作的期望收益，比最优动作少多少？”

$$
q_*(a^*) - q_*(A_t)
$$

在 $T$ 步上的 **累积后悔值**（cumulative regret）为：

**累积伪后悔值。** 它回答“截至第 $T$ 轮，因为没有始终选最优臂，累计少获得了多少期望奖励？”

$$
\text{Regret}(T) = \sum_{t=1}^{T} \left(q_*(a^*) - q_*(A_t)\right)
$$

低后悔值意味着萧炎很快认出高收益聚气台，只在必要时为信息付出代价。线性后悔值表示可避免的损失以近似恒定速率累积；次线性后悔值则表示损失增长慢于时间，平均到每一步的后悔会逐渐下降。

若最优台均值为 $0.8$，萧炎连续三轮选择均值 $0.5,0.8,0.6$ 的台，则三轮伪后悔为 $0.3+0+0.2=0.5$。注意它不是“实际最优台奖励减实际所选奖励”：某一轮次优台也可能幸运地产生 $1$，但那不会使其期望差距凭空消失。这里采用的是由真实均值定义的**伪后悔**；文献也会研究基于实现奖励的后悔，读公式时要先看定义。

这揭示了探索的节奏：初入修炼室时，对各台所知甚少，广泛尝试是合理的；证据充分之后，还以同样强度乱试便是在浪费轮次。热血不是不计代价地冲锋，而是在不确定时敢试、看清之后敢定。

## 从斗气样本估计动作价值

后悔值规定了目标，却不会替萧炎做选择。要行动，他需要估计每座聚气台的价值。最直接的做法是计算观测奖励的样本均值，随后再把这个估计交给不同的探索规则。

若动作 $a$ 在时刻 $t$ 之前已被选择 $N_t(a)$ 次，得到的奖励依次为 $R_1, \ldots, R_{N_t(a)}$，则：

**样本平均动作价值估计式。** 它回答“只根据已经观测到的奖励，目前应把这座台估成多少？”

$$
Q_t(a) = \frac{1}{N_t(a)} \sum_{i=1}^{N_t(a)} R_i
$$

$Q_t(a)$ 是萧炎当前掌握的估计；在平稳设定下，$N_t(a)$ 越大，它通常越可靠。困难在于信息与选择互相依赖：不登上一座台，就无法了解它；不了解它，又很难判断是否值得登上。药老在这里扮演价值评估导师，却不能替环境揭晓真实均值。

例如奖励依次为 $2,8,5$，样本均值从 $2$ 变成 $5$，再变成 $5$。若第四次得到 $9$，新均值是 $6$，而不是把旧均值 $5$ 与 $9$ 直接相加得到 $14$。反例是非平稳聚气台：若某台真实均值会随时间漂移，给所有历史样本同样权重会反应太慢，常要改用固定步长，让新经验占更大权重。

样本均值可以增量更新，无需保存全部修炼记录：

```python
def update_sample_average(old_value: float, count: int, reward: float) -> float:
    """增量式样本均值更新 Q_n = Q_{n-1} + (R_n - Q_{n-1}) / n。"""
    return old_value + (reward - old_value) / count
```

`reward - old_value` 是这次斗气增益相对旧估计的预测误差；`1 / count` 让后期单个样本对估计的推动越来越小。奖励分布平稳时，这种“见得越多、心越稳”的更新是合适的。

## $\epsilon$-贪婪：偶尔踏上陌生聚气台

最直接的探索规则是 **$\epsilon$-贪婪**（$\epsilon$-greedy）。以概率 $1 - \epsilon$ 选择当前 $Q_t(a)$ 最大的聚气台，也就是利用；以概率 $\epsilon$ 暂时放下已有判断，在全部动作中均匀随机选择，也就是探索。

令 $\mathcal{A}_t^*=\arg\max_{a'}Q_t(a')$ 表示当前所有并列最优动作。代码会在这些贪婪动作之间均匀打破平局；对于有限动作集 $\mathcal{A}$，策略为：

**含并列动作的 $\epsilon$-贪婪策略式。** 它回答“既保留随机探索，又公平处理多个当前最优动作时，每招概率是多少？”

$$
\pi(a) =
\begin{cases}
\dfrac{1-\epsilon}{|\mathcal{A}_t^*|} + \dfrac{\epsilon}{|\mathcal{A}|}, & a \in \mathcal{A}_t^*, \\
\dfrac{\epsilon}{|\mathcal{A}|}, & a \notin \mathcal{A}_t^*.
\end{cases}
$$

它的优势是简单而有底线：每个动作始终有非零概率被采样，大多数轮次又会交给当前最优估计。即使某座聚气台早期表现不佳，萧炎也不会永远把它封死。

它的弱点同样直接：固定 $\epsilon$ 意味着永远以相同比例随机探索。即使最优台已经几乎确定，萧炎仍会固定浪费 $\epsilon$ 比例的轮次，于是产生 **线性后悔值**。

数字例子：有 4 个动作、2 个并列贪婪动作，且 $\epsilon=0.2$。每个贪婪动作概率为 $0.8/2+0.2/4=0.45$，每个非贪婪动作概率为 $0.05$，总和为 $1$。常见误写是把每个贪婪动作都赋成 $1-\epsilon+\epsilon/4=0.85$，两个并列项便已超过 $1$。

```python
def select_epsilon_greedy(q_values: np.ndarray, epsilon: float, rng: np.random.Generator) -> int:
    """以概率 epsilon 随机选择动作，否则采取贪婪动作。"""
    if rng.random() < epsilon:
        return int(rng.integers(len(q_values)))
    return int(rng.choice(np.flatnonzero(q_values == q_values.max())))
```

## 衰减的 $\epsilon$-贪婪：从遍历到专注

药老给出的第一项改良，是让探索率随修炼轮次衰减。用从高位逐渐缩小的 $\epsilon_t$ 取代常数 $\epsilon$：

**反比探索率示意式。** 它回答“怎样让随机探索随轮次逐渐减弱？”这里的 $\propto$ 只表示一种量级关系，并非所有任务都必须采用这一精确调度。

$$
\epsilon_t \propto \frac{1}{t}
$$

早期，萧炎广泛踏查各座聚气台；后期，策略越来越贪婪。在平稳赌博机中，合适的衰减常能在经验上得到次线性（$\log T$ 或 $\sqrt{T}$）的累积后悔，因为随机探索次数不再与 $T$ 成比例。

```python
def epsilon_schedule(step: int, c: float = 1.0) -> float:
    """衰减的 epsilon 调度：epsilon_t = min(1, c / (t + 1))。"""
    return min(1.0, c / (step + 1))
```

比例常数 $c$ 决定萧炎何时从踏查转向专注。当 $c = 1$ 时，探索可能衰减得太快，还没充分尝试其余动作便被一次幸运样本锁在次优台上。把 $c$ 设在臂数 $K$ 的量级，会让前约 $K$ 轮保持 $\epsilon_t=1$ 的完全随机探索，提高各臂得到样本的概率，但仍不保证逐臂覆盖；若必须保证，可在正式更新前显式让每个臂各试一次。

衰减不是越快越好。太快会被偶然的高奖励误导，太慢则长期接近固定 $\epsilon$-贪婪。真正要随证据改变的是探索强度：不确定时多问几座台，确信后把轮次集中到最优候选。

## UCB：药老的乐观上界

$\epsilon$-贪婪随机挑选探索对象，却没有问“哪座台最缺证据”。**上置信界**（Upper Confidence Bound, UCB）把价值估计与不确定性同时写进选择规则，让每次探索都有明确目标：

**上置信界动作选择式。** 它回答“综合当前均值与证据不足带来的乐观余量，下一轮选哪座台？”

$$
A_t = \arg\max_a \left[ Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right]
$$

第一项 $Q_t(a)$ 偏爱已显示高平均奖励的聚气台；第二项是探索奖励（bonus），可理解为药老为“尚未看清的潜力”加上的乐观余量。某臂尝试次数少时余量大，尝试次数多时余量小。

分母 $N_t(a)$ 使反复采样后的不确定性迅速缩小；分子 $\ln t$ 缓慢增长，使被忽略很久的臂重新获得检查机会；常数 $c$ 控制乐观程度。注意，这个 bonus 是算法用于选择的附加项，不是环境真正发出的奖励。

这就是 **面对不确定性的乐观**（optimism in the face of uncertainty）。萧炎不是无目的地随机换台，而是对“可能很好但证据不足”的动作保持乐观。若尝试后结果平平，计数增加、置信奖励收缩，同类错误便不容易反复发生。

在典型 UCB1 中，当奖励限定在 $[0, 1]$ 时，探索奖励为 $\sqrt{2\ln t / N_t(a)}$。本章使用带可调 $c$ 的版本；精确的 $\sqrt{2}$ 来自特定后悔上界证明，这里不展开，而实践中 $c$ 通常也作为超参数调整。

```python
def select_ucb(q_values: np.ndarray, counts: np.ndarray, step: int, c: float) -> int:
    """平稳赌博机上的上置信界动作选择。"""
    untried_actions = np.flatnonzero(counts == 0)
    if len(untried_actions) > 0:
        return int(untried_actions[0])
    bonus = c * np.sqrt(np.log(step + 1) / counts)
    return int(np.argmax(q_values + bonus))
```

第一个分支让每座聚气台至少被尝试一次，避免 $N_t(a)=0$ 导致除零。此后，萧炎每轮选择“当前样本均值 + 置信奖励”最大的动作。

例如在同一轮，甲台 $Q=0.7$、bonus 为 $0.1$，总分 $0.8$；乙台 $Q=0.5$、bonus 为 $0.4$，总分 $0.9$。UCB 会先试乙，并非断言乙的真实价值更高，而是认为“排除乙的潜力”更值得当前这次信息成本。若乙被多试几次仍普通，它的 bonus 会缩小，选择自然回到甲。

## 汤普森采样：从可能世界中抽一签

UCB 显式添加不确定性奖励，**汤普森采样**（Thompson sampling）则采用贝叶斯方法。药老不再只写一个均值，而是为每座聚气台的平均奖励维护一个后验分布。每一步：

1. 从每个臂的后验中采样一个可能的均值。
2. 选择采样均值最高的臂。
3. 观察奖励并更新所选臂的后验。

对于奖励只能为 0 或 1 的伯努利赌博机，可以给每个臂使用 Beta 后验。成功次数多的聚气台，其后验会集中在较高均值附近；尝试较少的台，后验更宽，因此偶尔会抽出乐观样本并获得探索机会。

这形成概率匹配（probability matching）：在当前后验下，一个臂被选中的频率与它成为最优臂的后验概率相对应。像 UCB 一样，汤普森采样会在证据少时主动探索，并随信息积累自然转向利用。

```python
def select_thompson(alpha: np.ndarray, beta: np.ndarray, rng: np.random.Generator) -> int:
    """从 Beta 后验中采样并挑选样本最好的臂。"""
    samples = rng.beta(alpha, beta)
    return int(np.argmax(samples))
```

`alpha` 和 `beta` 是每个臂的 Beta 后验参数，即成功次数加一、失败次数加一。函数从每个后验抽取一个可能均值，再返回样本最大的动作。

比较两座台：甲记录 90 胜 10 负，后验集中在约 $0.9$；乙只记录 1 胜 0 负，均值看似更高却极不确定。纯贪婪会偏向乙，UCB 会显式给乙不确定性 bonus，汤普森采样则让乙的宽后验有时抽高、有时抽低。若两台都已有成千上万次记录，后验变窄，汤普森采样也会很少为不确定性绕路。三十轮探索可在河东，证据汇聚之后便该让利用走到河西——这是教程段子，不是原著台词。

<Callout title="聚气台还不是完整的修炼世界" type="tip">
这场试炼只教授探索，没有延迟奖励、状态访问或贝尔曼方程。萧炎每轮面对的局面相同，药老也只需评估动作的平均收益。下一章会让时间真正流动起来：状态出现，行动会改变未来，价值必须跨越多步计算。
</Callout>

## 实验：伯努利聚气台

可运行示例仍使用标准的平稳伯努利赌博机，只把它理解为“每座聚气台以固定概率带来一次成功增益”。实验比较固定 $\epsilon$-贪婪、衰减 $\epsilon$-贪婪、UCB 与汤普森采样，并在多个独立问题上绘制平均累积后悔值。

预期现象很清楚：固定 $\epsilon$-贪婪持续支付稳定的探索代价；衰减探索、UCB 与汤普森采样则在平稳设定中逐渐弯向次线性的累积后悔。图线不是“哪次奖励更热血”，而是不同策略为识别最优动作付出了多少长期代价。

## 下一场试炼：让行动改变未来

在聚气台房间里，萧炎学会了在没有状态变化时估计动作价值。走出房门后，一次选择将改变下一刻的处境：修炼、历练或筹备会把他送往不同状态，也会影响更远的回报。下一章用马尔可夫决策过程描述这条“三年成长”轨迹——局势或许会转移，但成长不能只靠一次幸运奖励。
