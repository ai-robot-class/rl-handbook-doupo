> **摘要.** 当状态多到写不进一张表时，萧炎需要一套能从相似经历中泛化的估值功法。DQN 保留 Q-learning 的核心目标，却用神经网络 $Q_\theta(s,a)$ 替代表格。函数近似、自举和异策略数据相遇后可能不稳定，因此药老给出两件稳定器：像纳戒一样存取旧经历的**经验回放**，以及隔一段时间才更新一次的**目标网络**。前者降低样本时序相关并复用数据，后者减缓目标漂移。

> 本章的纳戒、修炼卷轴和药老点拨均为教程原创类比，并非原著情节或人物原话。萧炎仍是智能体，斗气大陆仍是环境；药老解释价值估计与训练稳定性，不充当策略本身。

表格 Q-learning 为每个状态—动作对单存一个数。上一章的小型悬崖网格只有少量状态与四个动作，尚能逐格记账；连续观测一来，表就迅速失效。CartPole 给出四维观测，Atari DQN 通常接收经预处理的图像帧堆栈，完全相同的输入可能几乎不再出现，表也无法在相近输入间泛化。

这里必须分清 **状态** 与 **观测**：状态是满足马尔可夫性质的环境信息，观测只是智能体实际看见的信号，未必完整揭示状态。下文沿用标准公式写 $s$；在代码中，网络实际吃到的是环境返回的观测。只有当观测足以表示马尔可夫状态（或通过帧堆叠等构造近似状态）时，两者才可直接等同。

DQN 的核心举措很直接：用神经网络近似动作价值。与其显式存储 $Q(s,a)$，不如学习参数为 $\theta$ 的 $Q_\theta(s,a)$。对离散动作空间，常见架构输入一个状态表示，为每个动作输出一个标量；一次前向传播，便同时得到所有候选招式的 Q 值。

按全书统一路线，表格控制与 DQN 都属于“斗灵阶段”；DQN 只是把逐格记忆进一步换成能在相似输入间泛化的函数近似。这个比喻只表示知识递进，不表示 DQN 总比表格 Q-learning 强；在小型有限 MDP 上，表格法往往更可解释，也更容易得到收敛保证。

贪婪动作仍是 $\arg\max_a Q_\theta(s,a)$，所以 DQN 依旧是基于值的方法。这个经典输出头面向有限离散动作集，网络要能一次列出所有动作价值；它不能直接照搬到任意连续动作空间。

如果两个输出同为 $3.2$，它们在数学上并列贪婪；`argmax` 的某个实现返回首个索引，只是平局规则，不证明第一招更优。训练时可随机打破平局，评估时也应把规则写清楚。

## 把估值修炼写成回归问题

从这里起，一条历练记录紧凑写为 $(s,a,r,s')$，即把 $(S_t,A_t,R_{t+1},S_{t+1})$ 的时间下标省掉。$r$ 是这一转移的即时奖励，$Q$ 则估计从某状态—动作对出发的长期折扣回报，二者仍不可混为一谈。

药老先把 Q-learning 改写成类似有监督回归的任务。贝尔曼最优方程说明最优动作价值函数满足：

**最优动作价值贝尔曼最优方程。** 它回答“固定当前动作后，对环境随机结果取平均，并在下一状态继续选最佳动作时，长期价值是多少？”

$$
q_*(s, a) = \mathbb{E}\!\left[r + \gamma \max_{a'} q_*(s', a')\right],
$$

期望针对环境随机产生的奖励 $r$ 与下一状态 $s'$。拿到一条真实转移 $(s,a,r,s')$ 后，右侧便给出 $Q_\theta(s,a)$ 的单样本目标；训练让当前预测朝它靠近，并最小化平方误差：

**DQN 单步目标与均方 TD 损失式。** 前半式回答“这一条经验给出什么训练目标”，后半式回答“在线网络预测与目标相差多少”。

$$
y = r + \gamma \max_{a'} Q_\theta(s', a'), \qquad L(\theta) = \mathbb{E}_{(s,a,r,s')}\!\left[\bigl(y - Q_\theta(s,a)\bigr)^2\right].
$$

可以把它看成"标签会动"的回归：输入是状态表示，预测是所选动作的 Q 值，$y$ 是训练目标。普通回归的标签通常固定；这里的标签却部分来自正在训练的价值函数本身。

数字例子：若 $r=2$，$\gamma=0.9$，下一状态两招由目标网络估成 $[4,7]$，则非终止目标 $y=2+0.9\times7=8.3$。若预测 $Q_\theta(s,a)=6$，该样本平方误差是 $(8.3-6)^2=5.29$。若这一步是真正终止，目标应是 $2$；若只是时间上限截断且底层任务仍延续，通常仍应保留后继自举项。

有一条不可忽略的训练规矩：梯度只通过预测 $Q_\theta(s,a)$ 回传，不通过 $y$ 回传。这是 **半梯度**（semi-gradient）更新——哪怕目标由网络估计构造，本次优化也把它当常数。若同时沿目标反传，优化问题便不再是标准 DQN 所定义的固定目标 TD 回归。

更深的问题是，若预测 $Q_\theta(s,a)$ 和目标 $y$ 都由同一个即时更新的 $\theta$ 产生，每次梯度步都会顺手移动追逐目标。萧炎刚按一份评估卷修正估值，卷上的答案也同时被改写；误差面不断变化，训练便可能振荡甚至发散。朴素方案并非在所有任务上必然失败，但缺少稳定机制，通常不可靠。

接下来先识别根源，再用纳戒回放与固定评估卷分别缓解样本相关和目标漂移。

## 药老的警告：致命三元组

在拿出稳定器之前，药老先圈出 **致命三元组**（deadly triad）：下列三种元素同时出现时，价值学习存在不稳定与发散风险：

1. **函数近似**（function approximation）——同一网络用共享参数表示大量状态—动作价值；
2. **自举**（bootstrapping）——目标包含另一个学出来的估计 $\max_{a'}Q(s',a')$；
3. **异策略学习**（off-policy learning）——数据可能来自旧的探索行为，而目标指向当前贪婪策略。

每一项单独都很有用；合在一起，尤其配上非线性网络时，却可能形成反馈回路：一个样本通过共享权重改变许多估值，这些新估值又成为下一轮自举目标，而训练数据分布还可能来自另一套行为策略。DQN 并未从理论上消灭致命三元组，只用工程机制显著缓解风险。

把三项拆开看更清楚。只用表格 Q-learning，虽有自举与异策略，条目之间不共享神经网络参数；只做监督回归，虽有函数近似，却没有目标自举；只做同策略 MC，目标来自完整回报，也避开了自举。危险不是“出现任一项就会发散”，而是三者联手后存在反常放大的可能。

## 问题一：连续经历彼此太像

在线收集的转移通常不是独立同分布样本，时间相邻者高度相关。Atari 的连续帧往往只差少量像素：角色仍在同一场景，敌人位置也近乎不变。若按到达次序直接组成 minibatch，就像萧炎连续抄写同一类战况，梯度信息缺乏多样性。

这样会反复打磨眼前一小片经验；一旦进入新区，权重又集中拟合新数据，旧知识容易被覆盖，学习曲线也可能剧烈起伏。相关性不是遗忘的唯一原因，但会让随机梯度估计更偏、更不稳定。

若每条转移只用一次便丢弃，也会浪费数据：一次罕见而信息丰富、产生大 TD 误差的遭遇，仅推动一个梯度步便永远消失。

**经验回放**（experience replay）把每条转移收入容量有限的缓冲 $\mathcal{D}$。在本教程的原创比喻里，这个缓冲就是萧炎的"纳戒经验卷宗"：可存旧经历，也可随机抽出重练。

**经验回放转移记录式。** 它回答“纳戒里每条经验至少保存哪四项交互信息？”实际实现还常保存终止标志，以决定是否自举。

$$
(s_t, a_t, r_t, s_{t+1}).
$$

训练从纳戒般的缓冲中均匀随机抽取 minibatch，把不同片段、不同训练阶段的记录混在一起，从而**降低**而非绝对消除时间相关性。同一转移还能多次进入 minibatch，提高数据利用率。

回放与 Q-learning 很合拍，因为后者是异策略方法。几千步前由更大 $\epsilon$、更旧行为策略收集的转移仍可用于学习当前贪婪目标：目标对 $s'$ 做贪婪取值，并不要求旧行为当时实际选择的下一动作进入更新。不过，数据覆盖与分布偏移仍会影响学习质量，"异策略"不等于任意旧数据都同样有用。

## 问题二：评估卷答案一直在动

经验回放缓解样本相关，却修不好目标漂移：若 $y = r + \gamma\max_{a'}Q_\theta(s',a')$ 由正在更新的同一网络计算，每次改变 $\theta$ 都会改写目标，优化器脚下的损失地形随之移动。

**目标网络**（target network）像药老暂时封存的一份评估卷：参数 $\theta^-$ 在一段时间内固定，只负责给出自举目标；**在线网络**（online network）参数 $\theta$ 则每个梯度步都学习。有了冻结的 $\theta^-$，目标变成：

**固定目标网络的 DQN 目标式。** 它回答“怎样让自举标签在若干梯度步内不随在线网络同步漂移？”

$$
y = r + \gamma \max_{a'} Q_{\theta^-}(s', a').
$$

因为 $\theta^-$ 跨越许多更新保持不变，萧炎可以对同一版答案练上一阵；一连串梯度步因而更接近固定目标回归。

**硬拷贝**（hard copy）每隔 $C$ 次指定的训练/环境步（具体实现须明确计数口径）用在线参数覆盖目标网络：

**目标网络硬同步式。** 它回答“到达同步时刻时，怎样一次性把在线网络参数复制给目标网络？”

$$
\theta^- \leftarrow \theta.
$$

Nature DQN 的经典设置每 10,000 个智能体步更新一次目标网络。另一方案是 **软 Polyak 更新**（soft Polyak update），每步用小混合系数 $\tau$ 渐进更新：

**目标网络 Polyak 软更新式。** 它回答“怎样让目标参数以比例 $\tau$ 缓慢追随在线参数？”

$$
\theta^- \leftarrow \tau\,\theta + (1 - \tau)\,\theta^-.
$$

这样目标网络缓慢追随在线网络。硬拷贝是经典 DQN 配方；软更新会在第 3 章 Actor-Critic 的连续控制方法中再次出现。

若在线参数某一维为 $10$、目标参数为 $6$，$\tau=0.1$，一次软更新后目标参数为 $0.1\times10+0.9\times6=6.4$，不是直接跳到 $10$。硬更新则在同步点直接变成 $10$。二者都在控制目标变化速度，只是时间形态不同。

## 探索火候：$\epsilon$ 调度

DQN 通常用衰减的 $\epsilon$-贪婪行为收集数据。初期 $\epsilon$ 高，萧炎广试招式，纳戒里积累多样转移；随后衰减至小下限，让行为主要利用已学 Q 函数，同时继续收集少量新经验。

退火速度决定火候：降得太快，Q 函数尚不可靠时缓冲便被近贪婪数据占满；降得太慢，随机动作又会长期主导。线性衰减常作为稳妥起点，具体长度仍取决于环境，至少应覆盖价值估计尚不足以引导探索的阶段。

## 完整修炼循环：行动、入戒、抽卷、校准

把经验回放、目标网络和 $\epsilon$ 调度合在一起，DQN 便在行动、存储与学习间交替：

```
用相同的随机权重初始化 Q_theta 与 Q_theta_minus
初始化回放缓冲 D

对每个环境步：
    用 epsilon-greedy(Q_theta(s)) 选择动作 a
    执行环境，观察 r, s', terminated, truncated
    把 (s, a, r, s', terminal=terminated) 存入 D
    若 terminated 或 truncated，则结束当前片段

    如果 |D| >= batch_size：
        从 D 中均匀采样一个 minibatch
        对终止转移：     y = r
        对非终止转移：y = r + gamma * max_a' Q_theta_minus(s', a')
        更新 theta 以最小化 (y - Q_theta(s, a))^2

    每 C 步：把 theta 复制进 theta_minus
```

四条规矩不能漏。第一，目标网络以在线网络参数的副本起步，而非独立随机初始化。第二，缓冲积累到足够样本后才开练，初期只行动和存储。第三，真正的终止转移没有后续回报，自举项必须置零；示例遇到 `terminated` 或 `truncated` 都结束当前 rollout，但只有 `terminated` 被写入 `terminal` 掩码，时间上限截断仍从 $s'$ 自举。第四，硬更新设置中，目标网络只在每 $C$ 步同步，其余时间保持冻结。

> **纳戒小剧场。** 三十批新样本在河东，三十批旧卷宗在河西；莫欺旧经验年代久，只要覆盖相关局面，它仍能纠正今日的估值。药老又补一句：“也莫把纳戒当万能仓库，分布完全不覆盖目标状态，翻一万遍也学不出凭空的答案。”这是教程原创段子，不是原著对白。

## 原创平衡斗技：CartPole

本教程把 **CartPole-v1** 称作药老安排的原创"平衡斗技"，只为叙事方便，底层任务仍是标准 Gymnasium 环境。智能体收到四维观测：小车位置、速度、杆角度与杆角速度；动作只有左推或右推。杆角度越过约 12 度、或小车越出位置阈值时环境终止；`v1` 默认时间上限为 500 步，通常每存活一步奖励 1，因此走满上限的片段回报为 500。

Q 网络是一座双隐藏层 MLP "估值炉"，把四维观测映射为两个 Q 值，每个动作一个：

```python
class QNetwork(nn.Module):
    """双隐藏层 MLP：状态 -> 每个离散动作的 Q 值。"""

    def __init__(self, state_dim: int, hidden_dim: int, n_actions: int) -> None:
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.out = nn.Linear(hidden_dim, n_actions)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """前向传播：状态 -> 各动作的 Q 值。"""
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.out(x)
```

一次前向传播产出左右两招的 Q 值，`argmax` 选贪婪动作。损失是平方 TD 误差，梯度只穿过在线预测：

```python
def compute_td_loss(
    q_net: QNetwork,
    target_net: QNetwork,
    states: torch.Tensor,
    actions: torch.Tensor,
    rewards: torch.Tensor,
    next_states: torch.Tensor,
    terminals: torch.Tensor,
    gamma: float,
) -> torch.Tensor:
    """单步 DQN 平方 TD 误差损失。"""
    q_values = q_net(states).gather(1, actions.unsqueeze(1)).squeeze(1)
    with torch.no_grad():
        next_q = target_net(next_states).max(dim=1).values
        targets = rewards + gamma * (1.0 - terminals) * next_q
    return F.mse_loss(q_values, targets)
```

`gather` 从动作向量里挑出实际执行动作的 Q 值；`terminals` 是“真正终止”掩码，不包含单纯时间截断。目标块外的 `torch.no_grad()` 把 $\theta^-$ 当作常数，确保梯度不流入固定评估卷。

这场教学试炼运行 600 个片段：隐藏维度 128，学习率 $2\times10^{-3}$，折扣 $\gamma=0.99$，纳戒式回放容量 10,000。缓冲积累 500 条转移后开练，固定评估卷每 50 次梯度更新与在线网络同步；$\epsilon$ 在前 5,000 个环境步从 1.0 线性降至 0.05。

## 下一程：把 DQN 的弱点逐个击破

DQN 让萧炎从有限 Q 表走向可泛化的神经估值：纳戒式回放降低经验相关，固定评估卷减缓目标漂移。但这还不是终点——最大化会带来过高估计，均匀抽卷会浪费更新，单一标量也压扁了回报分布。下一章将这些弱点逐个摆上药老的修炼案台：双重估值、对偶结构、优先卷宗与 Rainbow 会分别改造原始配方。
